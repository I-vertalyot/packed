# Photos for the "i" button

Every picture in this folder can appear when someone taps the **i** button next to "Made by" in the app.
Each tap (and "Next photo") shows a random one.

**Add a photo:** on github.com open this `photos` folder → **Add file → Upload files** → drop your pictures → **Commit changes**.
**Remove a photo:** open it here → ⋯ menu → **Delete file**.

Supported: .jpg .jpeg .png .webp .gif .avif — keep each under ~500 KB so it opens quickly on phones.
New photos show up in the app within a minute or two; no code changes needed.
